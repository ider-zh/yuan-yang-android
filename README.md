# 原样 / Frame Again · 0.7.0

Android 7.0+ 原生相机。连续记录同一个拍摄主题，把照片做成 GIF 或 MP4。无需账号、不联网，照片只存在本机。

## 这版怎么用

- **打开就拍。** 首次进入「默认相册」，以后直接在上次使用的相册拍摄。左上进入所有相册；每行有封面，点一行即切换并打开相机，可在右上新建相册。相机左下角点最近一张的缩略图（空相册显示相册图标），可直接查看当前相册。
- **切换前后镜头。** 底部圆形快门固定居中；右侧图标一键切换并记住上次使用的镜头。只有一个方向的摄像头时，不显示切换图标。
- **叠影是上一张照片，不是自动定位。** 有参考照时，点右上「叠影设置」，可隐藏或调透明度。旧点位照片仍能在原相册里查看。
- **看大图或批量管理。** 相册按日期展示缩略图。点照片全屏查看，支持双指和双击缩放；放大后可以拖动，也可以切换照片、设为当天选片或删除。长按照片或点「选择」进入多选，批量删除前要确认；删除不影响之前另存的 GIF 或 MP4。
- **按天或全部导出。** 点「制作影像」，在底部面板选择每天一张或全部照片、是否对齐人物，然后直接点 GIF 或 MP4。默认每个本地日期选最后一张。
- **先预览，再分享或另存。** GIF 和 MP4 生成后直接打开 App 内的「导出预览」。看完可以点「保存到文件」选择保存位置，也可以点「分享到其他应用」。取消另存不会清掉预览，也不用重做导出。预览不是永久保存，要保留成品请另存。

## 导出时对齐人物（试验功能）

1. 在相册底部的「制作影像」面板，用「全部照片」或跨天选片，选至少两张，勾「对齐人物」再选 GIF 或 MP4。
2. 在手机上从第一张可用照片找参考姿态。用单人的双肩、髋部为主，计算平移、等比缩放和小幅旋转。所有照片对同一张参考图，不累积前一帧的误差。样式、衣服和背景本身不参与匹配。
3. 对齐可能轻微裁边，以免在边缘留下空白。角度差太大、多人、关键部位遮挡或裁剪超出限度时，不强制拉伸，结果会注明未对齐。开关只改变成品，原图仍在本机且不改动，不需要上传人像。
4. 效果取决于角度和构图，优先使用肩膀、髋部可见、相机高度接近的单人照片；从正面转到明显侧面不能靠二维对齐恢复。

## 安装包和旧版数据

随包交付的是可并装的「原样测试版」：与 0.2.1 使用不同的 App 标识，不覆盖旧版，也不会读走旧照片。**请不要先卸载旧版**。首次安装测试版从空相册开始；若此前已安装同签名的 0.3.0 至 0.6.0 测试版，可直接覆盖以保留测试版相册。

如果找不到既有测试版签名，可用 `./build-apk.sh --parallel-preview` 生成不同应用标识的「原样 · 并行测试版」。它可与旧版共存，但独立存储，初次打开是空相册。不要为了安装它卸载旧版。
如找回 0.2.1 的原签名，可构建同 App 标识的覆盖升级版；源码继续兼容旧相册及照片文件，不改变旧记录格式。没有原钥匙的不同签名不能覆盖 Android 已安装的版本。

## 构建和回归

- 使用 JDK 17+、Android API 34 SDK 和 Build-Tools 34.0.0。Gradle 构建会从 Google Maven 解析 MediaPipe 依赖；模型已作为固定版本随源码提供。命令行构建先运行一次 `./fetch-mediapipe.sh` 下载并校验固定版本的官方 AAR/JAR（可用 `YUANYANG_MEDIAPIPE_DIR` 指定缓存），然后可离线执行 `ANDROID_SDK_ROOT=/path/to/sdk ./build-apk.sh --preview`；也可配合本地 AOSP 工具使用 `ANDROID_PLATFORM_JAR`。`--preview` 使用单独的测试签名。
- 覆盖升级构建：使用 `YUANYANG_KEYSTORE` 指向原签名钥匙库，执行 `./build-apk.sh`（原调试别名和口令）；脚本验证签名摘要，不匹配会拒绝生成覆盖包。不要将签名私钥放入交付包。
- `tests/check-pose-alignment.sh` 验证几何对齐和拒绝不可靠输入；`tests/check-timeline.sh` 检查日期、顺序与选片；`tests/check-timelapse-media.sh` 检查 GIF、色彩、时序、取消和分享类型。
- `python3 tests/smoke_ui.py --help` 查看 ADB 回归选项。涉及模拟拍照、清除或删除照片的用例只在空白测试模拟器运行，不要用于主力手机。
- 调整相机、相册和预览交互前，可参考项目的 [Android 交互设计 Skill](.agents/skills/yuanyang-android-ux/SKILL.md)；`python3 tests/check_native_redesign_ui.py --help` 查看新版流程的模拟器验收选项。
